# Triage labels

The skills use five canonical triage roles. Apply the corresponding tracker
label when triaging issues in `Jackela/Novel-Engine`.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue. |
| `needs-info` | `needs-info` | Waiting on the reporter for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Deliberately not pursued; record the reason when closing. |

When a skill mentions a canonical role, use the tracker label in the same row.

## Existing category labels

- `bug` — confirmed defect in shipped behavior
- `enhancement` — new capability or improvement to existing behavior
- `documentation` — docs, spec, or openwiki work
- `duplicate` — already covered by another issue
- `invalid` — not a defect or request this repo will act on
