# Triage labels

Labels applied when triaging issues in Jackela/Novel-Engine:

- `bug` — confirmed defect in shipped behavior
- `enhancement` — new capability or improvement to existing behavior
- `documentation` — docs, spec, or openwiki work
- `duplicate` — already covered by another issue
- `invalid` — not a defect or request this repo will act on
- `wontfix` — deliberately not pursued; record the reason when closing
