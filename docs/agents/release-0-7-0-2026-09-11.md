Root cause (#496): the streaming pipeline joins provider deltas and validates
them as chapter markdown, but both HTTP adapters relayed the raw
`response_format: json_object` wrapper fragments, so the joined text was JSON,
not prose. Hermetic suites never saw it because the deterministic provider
streams bare markdown; #386's earlier live pass verified the sync path and
delta delivery, not the streamed job landing.

Fix (#497, implementer + main-session review): shared incremental unwrapper
`server/src/contexts/ai/infrastructure/providers/stream_json_unwrap.ts`
wired into both adapters' streaming extractors; port, pipeline, deterministic
provider, and streaming engine untouched. Validation on the fix branch:
type-check / lint / arch / gates / `spec:validate --strict` / server tests
(214 files / 1339 tests) all green. Squash-merged to main as `8207aad9`
(PR CI green: server, validate, container, Analyze). #496 closed with the
evidence comment.
