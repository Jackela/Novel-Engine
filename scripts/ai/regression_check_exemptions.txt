# Planned safety-keyword removal exemptions for scripts/ai/regression_check.py.
#
# Format (one entry per line, all three fields required):
#   <repo-relative path> :: <keyword> :: <reason citing a tracking issue>
#
# - <keyword> must be one of: raise, validate, sanitize, escape, auth, permission.
# - An entry only suppresses reports where deleted line path AND keyword both
#   match; other keywords on the same line are still reported.
# - Malformed lines make the guardrail fail loudly (fail closed).
# - The registry is version-controlled on purpose: every exemption shows up in
#   the same diff as the deletion it permits, so reviewers see both.
# - Remove entries once the planned refactor lands; this file should ship empty.
